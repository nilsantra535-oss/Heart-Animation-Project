# 💖 Heart Animation Project

A beautiful and smooth pulsating heart animation created using **HTML5 Canvas**, **CSS3**, and **JavaScript**.

## 🚀 Features
- **HTML5 Canvas Rendering:** Renders smooth particle effects to form a beating heart shape.
- **Responsive Design:** Automatically adjusts to mobile and desktop screens.
- **Dynamic Pulsing Effect:** Features a rhythmic scaling animation that mimics a real heartbeat.
